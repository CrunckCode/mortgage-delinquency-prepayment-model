# Interface contracts (frozen; changes go through the lead only)

Package: `python/mortgage_risk/`. Run everything from `python/` (`py -3 -m pytest -q`, `py -3 -m mortgage_risk.cli`).
Conventions: no em dashes anywhere; one clearly marked `# ===== CONFIG (user inputs) =====` / `# ===== END CONFIG =====` block at the top of each module (module-local settings only; shared settings live in `config.py`); column names only via `columns.py` constants (the only exception is the Freddie layout in `freddie.py`); comments one short line, WHY not WHAT; floats stored as float32 where large; every output json carries `"data_source"`.

## Data (Task A: macro.py, synthetic.py, freddie.py, data.py, targets.py, features.py)
- `macro.build_macro(start, end) -> DataFrame[PERIOD, STATE, MKT_RATE, HPI, UNEMP]` month-end rows per state.
- `macro.apply_shock(macro, shock: config.Shock, start: Timestamp) -> DataFrame` ramps rate (bp/10000 added to MKT_RATE), HPI (pct, multiplicative on HPI), UNEMP (points added) linearly over `shock.ramp_months` from `start`, then holds.
- `synthetic.simulate_panel(n_loans: int, seed: int = config.SEED) -> DataFrame` loan-month panel with columns: LOAN_ID, PERIOD, ORIG_DATE, VINTAGE, AGE, all origination attributes, CUR_UPB, CUR_RATE, DLQ_STATUS, DLQ_BUCKET, PREPAY_FLAG, DEFAULT_FLAG, ZB_CODE, IS_ACTIVE, MKT_RATE, HPI, HPI_ORIG, UNEMP, TRUE_HP, TRUE_HD. One row per loan per active month (rows stop after termination). `DEFAULT_FLAG=1` only on the first month DLQ_STATUS reaches 3. `PREPAY_FLAG=1` only on the payoff month. TRUE_* are the DGP hazards for that month.
- `synthetic.calibration_report(panel) -> dict` keys `pd12_train`, `pd12_oot_2020`, `cpr_mean`, `cpr_by_year`; also printed.
- `freddie.load_freddie(orig_glob, perf_glob, max_loans=None) -> DataFrame` same internal schema (no TRUE_*), macro columns filled from `data/raw/macro/*.csv` if present else synthetic macro with a logged WARNING.
- `data.get_panel(source="auto", n_loans=None, refresh=False) -> (panel, macro, meta)`; meta = `{"source": "synthetic"|"freddie", "n_loans": int, "seed": int}`; parquet cache in `config.INTERIM_DIR`.
- `features.add_features(df, macro=None) -> DataFrame` adds MTM_LTV, INCENTIVE (CUR_RATE - MKT_RATE, in percentage points), BURNOUT (cumulative months with INCENTIVE > 0.5 up to and including the row's PERIOD), SEASONING_RAMP (min(AGE/30, 1)), HPI_CHG_12M (percent change of HPI vs 12 months earlier, state level, backward only; first 12 months 0), UNEMP_CHG_12M, TIMES_30DPD_12M (count of months in last 12 with DLQ_STATUS >= 1, backward only), LOG_UPB, FICO_BAND, MONTH_OF_YEAR.
- `features.assert_no_leakage(df, feature_cols, asof_col=None)` raises AssertionError if any TRUE_*, target, ZB_CODE, DEFAULT_FLAG, PREPAY_FLAG is in feature_cols.
- `targets.build_snapshots(panel_feat) -> DataFrame` one row per (loan, snapshot month in config.SNAPSHOT_MONTHS) for loans active and DLQ_STATUS in (0,1) at snapshot, features as of snapshot, plus SNAPSHOT_DATE and TARGET_PD12 (1 if DEFAULT_FLAG fires in months t+1..t+12; prepay before default is 0; only snapshots whose 12-month window is fully observed before OBS_END).
- `targets.build_hazard_rows(panel_feat, loan_share=1.0, seed=config.SEED) -> DataFrame` loan-months at risk (DLQ_STATUS==0 at t-1 and active at t) with features taken at t-1 and TARGET_PREPAY_1M = PREPAY_FLAG at t; PERIOD is the month t.
- `targets.split_by_time(df, kind: "pd"|"prepay") -> dict[str, DataFrame]` keys `train`, `calib`, `oot` using the windows in config (snapshot date for pd, PERIOD for prepay).
- Real vs synthetic: all of the above must work identically on either source.

## Models and evaluation (Task B: scorecard.py, models.py, evaluation.py)
- `scorecard.fit_bins(x, y, max_bins=8, min_share=0.05, monotone=True) -> BinSpec`; `woe_transform(df, specs) -> DataFrame`; `fit_scorecard(df, y_col, features) -> Scorecard` (statsmodels Logit, IV filter config.SCORECARD_IV_MIN, sign check); `Scorecard.predict_pd(df)`; `Scorecard.points(df)`; `export_scorecard_table(sc) -> DataFrame[variable, bin_lo, bin_hi, woe, coef, points]` plus `sc.intercept`, `sc.factor`, `sc.offset`.
- `models.ModelBundle` dataclass: `.name`, `.kind` ("logit"|"xgb"|"lgbm"), `.target` ("pd"|"prepay"), `.features`, `.estimator`, `.calibrator`, `.predict_pd(df)` / `.predict_smm(df)` (calibrated probability), `.predict_margin(df)` (raw GBM margin, for SHAP), `.save(path)`, `ModelBundle.load(path)`.
- `models.fit_logit_prepay(train_df) -> ModelBundle` (piecewise-linear INCENTIVE hinges at 0, 0.5, 1.0, 1.5 plus BURNOUT, SEASONING_RAMP, MTM_LTV capped at 120, FICO; statsmodels; `coefs` DataFrame exposed as `.coefs` for Excel).
- `models.fit_gbm(kind, train_df, target, features, params=None, monotone=None, calib_df=None) -> ModelBundle`; `models.tune_time_cv(kind, train_df, target, features, n_iter, folds) -> dict`; `models.calibrate(bundle, calib_df, method="auto") -> ModelBundle` (isotonic or Platt by lower Brier on calib_df).
- `models.train_all(splits_pd, splits_pp, quick=False) -> dict[str, ModelBundle]` keys `pd_logit`, `pd_xgb`, `pd_lgbm`, `pp_logit`, `pp_xgb`, `pp_lgbm`; saves joblib files to `config.MODEL_DIR`.
- `evaluation`: `auc, gini, ks, brier, decile_table(y, p, n=10), calibration_table(y, p, n=10), hosmer_lemeshow(y, p, n=10), psi(expected, actual, bins=10), csi(train_df, oot_df, features), delong_test(y, p1, p2) -> (dAUC, z, pval), bootstrap_ci(metric, y, p, groups=None, n=config.BOOTSTRAP_N, seed) -> (lo, hi), by_segment(df, seg_col, y_col, p_col), benchmark_table(bundles, splits, target) -> DataFrame`, `prepay_cpr_comparison(bundle, oot_df) -> DataFrame[PERIOD, actual_cpr, pred_cpr]`. Decile ranking: sort descending by score, ties broken by input order, equal-count deciles; AUC via rank statistic (average ranks for ties).
- Writes (Task B `evaluate_all(bundles, splits_pd, splits_pp)` in `evaluation.py`): `outputs/benchmark_pd.csv`, `benchmark_prepay.csv`, `deciles_pd_<model>.csv`, `calibration_pd_<model>.csv`, `psi_csi.csv`, `stability_by_vintage.csv`, `segments.csv`, `scorecard_table.csv`, `prepay_logit_coefs.csv`, `prepay_cpr_oot.csv`, `excel_inputs/loan_sample.csv` (2000 OOT snapshot rows: all FEATURES_PD plus TARGET_PD12, scorecard PD, GBM PD, UPB, seed fixed), `excel_inputs/psi_train_bins.csv`.

## Explain, scenarios, charts (Task C: explain.py, scenarios.py, export_hook.py, charts.py)
- `explain.shap_values(bundle, X) -> shap.Explanation` (TreeExplainer, raw margin); `global_importance(expl, features) -> DataFrame[feature, mean_abs_shap]`; `dependence_plots(expl, X, top_k=6, out_dir)`; `dgp_alignment(importance, target) -> DataFrame[feature, rank, expected, passed]`; `reason_codes(bundle, row_df, k=4) -> list[str]` using `config.REASON_TEXT`.
- `scenarios.project_portfolio(bundle_pd, bundle_pp, loans_asof, macro, shock, horizon=config.PROJECTION_MONTHS) -> DataFrame[month, smm, mdr, cpr, cdr, survival_upb, exp_defaults_upb, exp_prepay_upb]` (UPB-weighted, re-scoring each month with age+1, amortized UPB, BURNOUT rolled forward, shocked macro; default hazard from the 12-month PD as `1-(1-PD)^(1/12)` applied first, prepay on survivors); `project_truth(...)` same using the TRUE_* DGP; `summary_12m(curves) -> DataFrame`.
- `export_hook.write_curves(curves_by_scenario)` -> `outputs/waterfall_hook/cpr_cdr_curves.csv[scenario, month, smm, mdr, cpr_annual, cdr_annual, survival]` and `scalar_equivalents.csv[scenario, cpr, cdr, severity, lag]`; `to_waterfall_scenarios(path) -> list[dict]` with keys of `waterfall.config.Scenario`.
- `charts`: each function takes data and an output path, matplotlib only, plain style, 150 dpi: roc_ks, decile_lift, calibration, psi_bars, shap_bar, shap_beeswarm, shap_dependence, scenario_curves, prepay_cpr_oot, stability_vintage, model_vs_truth.
